# Contexto del Proyecto

## Nombre

PLG Capital

## Objetivo

Permitir la administración de ventas financiadas, control de pagos, clientes e inversionistas.

## Modelo de negocio

1. Se registra un producto.

2. Se registra un cliente.

3. Se realiza una venta.

4. La venta puede ser:

   * Contado
   * Crédito

5. En ventas a crédito:

   * Existe cuota inicial.
   * Existe saldo financiado.
   * Existen cuotas programadas.
   * Debe calcularse utilidad y capital.

## Futuro

* Gestión de inversionistas.
* Distribución de utilidades.
* Reportes financieros.
* Dashboard ejecutivo.
